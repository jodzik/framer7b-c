# Framer7b

## Общая концепция

Формат представляет собой модификацию классического BASE128, адаптированную для потоковой передачи данных.  
В отличие от стандартного BASE128, где каждый байт является исключительно частью полезной нагрузки (payload), 
данный формат использует старший бит (MSB, 8-й бит) для разделения потока на данные и управляющие команды.  

## Структура байта и фрейма

**0bMDDD_DDDD**, где M - маркерный бит определяющий назначение байта: 0 - байт данных, 1 - управляющий байт.  
Управляющих байта всего два:
- `0xD4` - START, начало пакета.
- `0x81` - END, конец пакета.

Структура фрейма:

```
[ START (0xD4) ] -> [ Payload Byte 1 (MSB=0) ] -> ... -> [ Payload Byte N (MSB=0) ] -> [ END (0x81) ]
```

## Алгоритм кодирования

BASE128 - это алгоритм кодирования, который упаковывает данные таким образом, 
что каждый выходной байт использует только 7 младших бит для хранения информации.  
Старший бит (MSB, 8-й бит) остается равным 0.  

Это позволяет:
- Представлять данные в виде "безопасных" байт, которые можно использовать в протоколах, где 
  8-й бит зарезервирован для служебных целей.
- Достигать эффективности 87.5% (7/8 = 0.875), что лучше, чем BASE64 (75%) или HEX (50%).

### Кодирование

Вход: N байт исходных данных.
Выход: ⌈N × 8 / 7⌉ байт закодированных данных.

Каждые 7 байт входных данных (56 бит) преобразуются в 8 байт выходных данных.  

```
Входные байты:   [B0] [B1] [B2] [B3] [B4] [B5] [B6]
                 8bit 8bit 8bit 8bit 8bit 8bit 8bit
                 ↓    ↓    ↓    ↓    ↓    ↓    ↓
                 56 бит данных
                 ↓
Выходные байты:  [O0] [O1] [O2] [O3] [O4] [O5] [O6] [O7]
                 7bit 7bit 7bit 7bit 7bit 7bit 7bit 7bit
```

### Декодирование

Вход: M байт закодированных данных
Выход: ⌊M × 7 / 8⌋ байт исходных данных

Каждые 8 байт входных данных (каждый по 7 бит = 56 бит) преобразуются обратно в 7 байт:

```
Входные байты:   [I0] [I1] [I2] [I3] [I4] [I5] [I6] [I7]
                 7bit 7bit 7bit 7bit 7bit 7bit 7bit 7bit
                 ↓    ↓    ↓    ↓    ↓    ↓    ↓    ↓
                 56 бит данных
                 ↓
Выходные байты:  [B0] [B1] [B2] [B3] [B4] [B5] [B6]
                 8bit 8bit 8bit 8bit 8bit 8bit 8bit
```

### Обработка остатка

Если количество входных байт не кратно 7, последний блок обрабатывается частично.  
При декодировании эти "хвостовые" нулевые биты игнорируются, так как мы знаем точную длину исходных данных.
